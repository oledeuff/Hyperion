# Slides HTML HyperION — séances 1 à 5

Dépôt conseillé dans le site GitHub Pages :

```text
/Hyperion/
├── assets/
│   └── tesseract-couleurs.png
└── slides/
    ├── index.html
    ├── seance-01.html
    ├── seance-02.html
    ├── seance-03.html
    ├── seance-04.html
    └── seance-05.html
```

Les cinq fichiers pointent vers `../assets/tesseract-couleurs.png`.

Navigation : flèches, PageUp/PageDown, espace, Home/End ; `F` pour plein écran ; `H` pour afficher l'aide.

Chaque numéro de diapositive est adressable par fragment d'URL, par exemple `seance-04.html#12`.
